# 按风险选择验证

仅执行与当前改动及项目要求相关的条目。命令从项目配置发现，不预设语言、框架、数据库或托管平台。

| 变化 | 优先证据 | 常见证明缺口 |
| --- | --- | --- |
| 文案、说明、链接 | 事实、引用和实际展示位置 | 截图无法证明链接目标或描述准确 |
| 界面交互 | 实际操作、结果和相关加载、空值、错误状态 | 构建通过无法证明交互可用 |
| 计算、解析、状态转换 | 独立期望值、边界输入和关键失败路径 | 测试只重复实现逻辑，错误可能两边一致 |
| 接口或共享模块 | 生产者、消费者及兼容性检查 | 单侧类型或单元检查漏掉真实边界差异 |
| 身份、权限、隔离 | 实际执行约束的位置，允许与拒绝路径 | 客户端限制无法证明服务端拒绝生效 |
| 持久化或迁移 | 隔离且有代表性的数据、执行顺序、失败恢复 | 内存替身或语句断言无法证明真实引擎行为 |
| 并发、重试、缓存 | 可控时序、重复调用、过期和取消 | 一次顺序执行未覆盖竞态和重复副作用 |
| 性能 | 相同条件下的前后测量及正确性回归 | 单次耗时或不同负载不能证明优化 |
| 依赖、构建、打包 | 项目锁定版本、实际产物和关键启动路径 | 源码测试不等于发行产物可运行 |

## 三类容易误判的证据

**测试失败。** 先判断是本次回归、需求改变、历史问题还是环境故障。仅在相关且可行时比较基线；有用户未提交改动时不要通过破坏工作区做对照。历史故障可以记录为范围外，但不能掩盖它对本次验证的影响。

**外部服务替身通过。** 只能证明在模拟条件下的本地行为。真实协议、权限、版本或网络行为需要相应集成证据；环境不可用时完成可执行检查，准确标明缺口，不自动连接生产服务补证。

**检查命令成功。** 看实际检查了什么：是否全跳过、仅编译、遗漏目标，或格式工具虽然退出成功却输出待修改文件。合理缓存可以复用，但须确认内容和输入匹配，不能把缓存本身当缺陷。

## 数据与发布

对有副作用的调用，超时或断连不代表未执行。重试前先核对执行结果与幂等或去重保障；无法确认且重复执行可能造成损失时，保留证据并暂停该动作，继续不依赖它的工作。

涉及不可逆数据变化时，在授权环境验证迁移顺序、兼容窗口及恢复办法。恢复可能依靠备份、补偿或向前修复，不强制假定存在无损回滚。备份方案不能代替实际可恢复性的证据。

发布在任务授权范围内时，将验证对应到实际源码与产物；同名版本号不证明内容相同。检查既有版本或标签，不默认覆盖。采用项目已有发布流程，不额外发明审批环节。记录已完成的发布动作及运行结果，未执行不能写成上线成功。
